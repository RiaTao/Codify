# Hello World HTML Page

This repository contains a simple HTML page that displays "HELLO WORLD" in all caps.

## Files

- `index.html`: The main HTML page that displays "HELLO WORLD" in all caps
- `test_index.html`: A browser-based test file to verify the HTML content
- `test.js`: A Node.js test script to verify the HTML content programmatically

## Running the HTML Page

Simply open the `index.html` file in any web browser to view the page.

## Running the Tests

### Browser Test
Open the `test_index.html` file in a web browser to run the browser-based tests.

### Node.js Test
To run the Node.js tests, execute the following command:

```
node test.js
```
