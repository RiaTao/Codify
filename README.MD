## HTML Hello World Page

This repository now includes an HTML page (`index.html`) that displays "HELLO WORLD" in all caps with "Title" as the page title.

### Files:
- `index.html` - The main HTML page displaying "HELLO WORLD" in all caps
- `test_html.py` - Unit tests to verify the HTML page meets requirements
- `requirements.txt` - Python dependencies for running tests

### Running the HTML page:
Open `index.html` in any web browser to view the page.

### Running tests:
1. Install dependencies: `pip install -r requirements.txt`
2. Run tests: `python test_html.py`

- ✅ HTML page says "hello world" in all caps ("HELLO WORLD")
